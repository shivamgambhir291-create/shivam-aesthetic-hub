# Shivam Gambhir Portfolio

## Goal
Build a polished, responsive one-page portfolio that presents Shivam as a BTECH CSE (AI&DS) student and content creator through a soft-luxury editorial visual language.

## Build
- Replace the blank home page with the complete portfolio: introduction, about, creative work, journey, interests, personal statement, contact, and minimal footer.
- Use an asymmetric magazine composition, ivory-led pastel gradients, restrained gold accents, serif display type, and a clean sans-serif body face.
- Generate a cohesive set of original portrait and creative-work imagery; keep image areas easy to replace later.
- Add restrained scroll reveals, gentle image motion, refined button/card interactions, and reduced-motion support.
- Make navigation and calls to action scroll to the relevant sections; make the contact form provide a clear local success state without adding data storage.
- Ensure tablet and mobile layouts retain clear hierarchy, readable type, and balanced spacing.

## Quality checks
- Add unique home-page metadata and accessible image descriptions.
- Verify the finished page in the live preview at desktop and mobile widths, including navigation, form behavior, and visual overlap checks.
